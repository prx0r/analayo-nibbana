## Future use (owner brief, 2026-10-26) — creative pause grammar

Wood blocks are the flexible layer: use them **inside pauses** —
attention hits that pull the ear back to what's being said, and emphasis
marks before major points. Bowls = intro/close. Ding = rare "wake up".
Long-break bell = section-scale pauses. Formula lives here so every
spiritual-works build gets the same kit.
