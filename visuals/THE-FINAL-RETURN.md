## Why this is so much more interesting

The film has established a contract with the viewer:

0 → A → B → C = more, more, more.

Path 2 makes that contract irresistible. Each return gives us more of the beautiful song, more of the beloved, more of life.

Path 3 shows the mechanism by which we keep getting more.

Path 5 examines the grasping that sustains that mechanism.

And Path 6B finally shows someone who doesn't renew it.

Then C does something the audience has never experienced from the essay before.

It doesn't reward the expectation of another revelation.

There's nothing left to watch.

But the viewer might still find themselves waiting for something.

That's the final perceptual experiment.
