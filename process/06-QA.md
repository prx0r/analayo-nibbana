# 06 — QA GATES. Every gate blocks the next stage.

## G1 totals reconcile (after 02)
Per-section kept durations sum to the full kept total. If not, the
assignment leaked spans. (Caught here: none — 20.70h both ways.)

## G2 seams read standalone (after 01, spot-checked in 03)
Sample cross-lecture joins per section; each must parse cold.
Fix: move boundary to sentence edge. Never rewrite.

## G3 motto-cap (after 02/gold)
Count motto-like opens per gold. Rule: 1 per core, ≤3 spaced per gold.
(Found here: §1 gold opened with 8 stacked mottos — every lecture
starts with the verse. Capped by rule.)

## G4 hold-up test (after cores built, before pads finalized)
For each beat: does the pad PRIME the clip? Verify by READING, not
counting — shared-vocabulary counts flag candidates (here: 47 flagged)
but the verdict is a human read: same question, same simile, same
doctrine? Fixes here were reassignments (Bahiya, magic-show, honey,
delight-mirror) plus one clip swap. The metric alone would have
approved garbage and cut gold.

## G5 provenance (after pads assigned, after EVERY edit touching text)
`verbatim == source[file][start:end]`, both sides normalized identically
(whitespace + markdown). Then INDEPENDENT re-extraction (different
splitter) must confirm. 75/75 → 76/76 here across two audits.
Rerun on any change. No provenance = no ship.

## G6 TTS scan (after gloss)
- No leading Pali sentences (Fish opens in English, always).
- No parens, colons, semicolons, bullets, mid-sentence starts.
- No orphaned punctuation ("—.", "the the", dangling "—").
- No false glosses (word-boundary check: "cessation" must survive;
  regression test kept in notes).

## G7 slop scan (continuous)
`slop/` inventory reviewed: every quarantined file has a dated reason.
No hand-written sentence may enter seg*_script, seg*_fish, or any TTS
line. Fish files contain mapped words/drops ONLY.

## G8 listen pass (needs ears — never automated away)
Fixed cores played end to end. Needed: join breaths, bell levels,
f1-f4 flags (monster clip split, heavy closer, thin section, L10
weight), cough hunt. Ears sign off or it doesn't ship.

## G5 provenance — semantic quote-anchor (rewritten 2026-10-24)
`process/scripts/g5_provenance.py`, called by verify.sh. Every
nanananda_verbatim must sit BETWEEN QUOTE MARKS in some `sermon-*.md`
(whitespace/markdown normalized, `**` stripped, outer-quote tolerant).
History: the original set-membership check built its span set with a
naive `"..."` pairing regex; sermon-30's off-by-one quote shifted all
later pairing (labels paired instead of content), so a semantically
valid quote would have been REJECTED by its own gate. Direct anchor
search (`"quote"` contiguous) is immune to pairing errors. First
inline-shell version broke on quote escaping (M-A7) — now standalone
file, file-mode tested before wiring (axiom 14/15).

## G6b hardened TTS gate (added 2026-10-24)
`process/scripts/g6_tts_check.py`, called by verify.sh after G6:
- G6a punctuation + diacritics (as before).
- G6b leading non-English run (>=4 words, zero function words) —
  the S5b2 class. Carries an embedded CANARY (the pre-fix line);
  if the detector stops flagging it the gate fails, so the gate
  proves its own detection on every run.
- G6c mid-sentence Pali terms must be gloss-attached (dash/paren/
  comma/quote marker within 40 chars, either side) or on APPROVED,
  where each of 12 entries states its reason.
History: reviews/REVIEW.md section D found 9 unglossed-Pali beats the old
G6 missed (it only checked diacritics while corpus is ASCII). See
MISTAKES.md M-A3..M-A6 for the detector/canary/shell/unicode lessons.

## verify.sh
Runs G1 (totals), G5 (provenance reconstruction), G6 (TTS pattern
scan), plus file-presence for all manifests/scripts/keys. Run before
every commit touching build outputs.
