# 11 — STICKINESS. Why this format sticks (science), and what else could.

Honest framing first: some of these effects are rock-solid (testing
effect, elaboration, dual coding, isolation), some are shaky
(Zeigarnik proper failed a 2025 meta-analysis for memory — though the
resume-tendency held). Below marks which is which. Nothing here changes
the doctrine layer; stickiness is arrangement + delivery only.

## Already in the build (often by accident — now on purpose)
- **Elaborative encoding** (Fabiani et al.: elaboration beats rote; P300
  predicts recall only for rote learners). Every plain-English gloss and
  every simile is elaboration. The Fish layer IS this effect.
- **Isolation / von Restorff** (1933, still replicating in 2025–26):
  distinctive items are recalled better. Our isolates: mottos, similes,
  bells, the 30s terminal silence. The 2018 retrieval-cue account says
  cues do the work — which is exactly what bells-as-retrieval-cues are.
- **Spaced revisiting**: seed → A → B → C is the same material
  at expanding intervals. That's distributed practice wearing a robe.
- **Retrieval + application gates**: the 12-level movie's behavioural
  gates (do it, log it, unlock) are retrieval practice with teeth —
  the single strongest effect in the learning literature.
- **Narrative organization**: similes carry abstractions (fire, whirlpool,
  cinema, dog, raft). Concrete beats abstract, always.
- **No-resolution ending**: ends on stilling, not climax. Unusual =
  memorable (isolation again), and honest to the content.

## Cheap adds (same build, no new doctrine)
1. **Cross-section open loops** (storytelling Zeigarnik, not the lab
   version — use it for curiosity/retention, not memory claims).
   Plant 2–3 questions early, close them late: "where did the fire go?"
   (§1 asks, §5 answers), "who is the watcher?" (§4 asks, §6 answers).
   Nested loops (Palahniuk/Inception structure): open in order, close in
   reverse. Mark each open→close pair in the manifest.
2. **Retrieval checkpoints**: before each section, one breath + "say the
   motto back" (silently counts). Testing effect, near-zero cost.
3. **Isolation audit per section**: every section needs ≥1 bell + silence
   moment already (it has them) — verify in QA, don't assume.

## Parked for another build (deliberately NOT this one)
- **A jokes track.** The humor effect is real (arousal + bizarreness +
  distinctiveness all predict recall), and the material HAS comic veins:
  the tavern drunk who sleeps instead of going to Colombo, the wrong
  road to Kandy, the dog barking at its own reflection, the mother
  cuddling someone who might be her dead father. But: comedy needs a
  comedian's hand, and one wrong joke poisons a liberation teaching.
  Rule: separate "jester cut" only — same spine, comedic bridges only,
  zero doctrinal invention. Never mixed into the main build.
- **New metaphors.** Tempting, forbidden. Nanananda's similes are
  sufficient and canonical; inventing ours is slop with better lighting.
  Emphasize his (visual treatment, timing, bells) — never author new ones.
- **Full visual dual-coding** (Paivio: verbal + visual codes double
  retention). That's packs 48/49 (HyperFrames) — a separate pipeline
  that consumes THIS build's manifests. Audio+text now, pictures later.

## Portability verdict: yes, any audio + text can run this
Universal (copies over unchanged): pipeline 01–06, gates incl. verify.sh,
speaker roles, bell grammar, math (ratios will differ per text; the
fractal shape won't — it's a property of condensing, not of Buddhism).
Source-specific (rebuilt per text): scaffold sections, keyword sets, pads,
key entries, metaphors, bells' anchor moments.
Pre-flight (from 00-INPUTS + 08-PORTING): quotable source? voice-marked
transcript? If either is missing, add it by hand ONCE before running —
the pipeline cannot invent what isn't marked.
Known failure modes: no quotable units (verbatim layer impossible —
paraphrase-flagged fallback, never silent invention); monotone single
take (joins harder — bells + silence cover it); no translation
(bilingual gloss step first, owner-vetted).
